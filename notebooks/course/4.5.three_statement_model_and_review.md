# Three-Statement Model and Review Memo

Module: Financial Statement Analysis and Financial Modeling

## Lesson summary

A three-statement model converts operating and financing assumptions into a
linked income statement, balance sheet, and cash flow statement. A strong model
does more than balance: its drivers are economically interpretable, its
historical values trace to sources, its formulas are consistent, and its
sensitivities expose the assumptions that matter.

This lesson builds a one-year forecast from the simulation used throughout the
module. All values are USD millions, rates are decimals in calculations, and
the fiscal year has 365 days.

## Learning objectives

By the end of this lesson, readers should be able to:

- organize a model into source, assumptions, schedules, statements, checks, and
  output layers;
- forecast revenue, margins, working capital, fixed assets, debt, interest,
  taxes, equity, and cash with explicit drivers;
- reconcile FCFF, closing cash, retained earnings, and the balance sheet;
- design base, downside, and upside cases without overwriting history;
- identify circularity and false-plug errors;
- write a model review memo that separates facts, assumptions, sensitivities,
  and unresolved risks.

## Prerequisites and notation

Complete Lessons [4.1](4.1.analysis_framework_and_statement_linkages.md) through
[4.4](4.4.specialized_entities_and_consolidation.md).

The forecast uses simple annual growth, a 25% tax rate, and days-based working
capital. Interest is modeled as a stated USD 25m assumption to avoid an
interest-cash-debt circularity in this teaching example. A production model
would use an average-debt schedule and an explicit circularity policy.

## Model architecture

Use separate layers:

1. **Sources:** immutable historical values, filing dates, page references, and
   snapshot vintages.
2. **Adjustments:** reclassifications and normalized-history bridges.
3. **Assumptions:** scenario-specific operating, tax, capital, and financing
   drivers.
4. **Schedules:** revenue, working capital, fixed assets, debt, interest, tax,
   equity, and share count.
5. **Statements:** income statement, balance sheet, and cash flow statement.
6. **Checks:** balance, cash, retained earnings, fixed assets, debt, signs,
   units, and scenario integrity.
7. **Outputs:** ratios, cash flow, sensitivity, valuation inputs, and memo.

Hardcoded historical facts should not be mixed with forecast formulas. Use
consistent colors or cell styles in a spreadsheet, but never rely on color
alone: label the source, formula, and scenario in machine-readable fields.

## Forecast drivers

### Revenue and operating profit

Forecast revenue at the lowest level supported by evidence:

```{math}
\text{Revenue}
=\sum_i
\text{Volume}_i\times\text{Price}_i
\quad\text{or}\quad
\sum_i\text{Customers}_i\times\text{Revenue per customer}_i.
```

A top-down growth rate can be a useful cross-check, not a substitute for
understanding volume, price, mix, capacity, retention, and currency.

### Working capital

With explicit day assumptions:

```{math}
\text{Receivables}_t
=\text{Revenue}_t\times\frac{\text{DSO}_t}{365},
```

```{math}
\text{Inventory}_t
=\text{COGS}_t\times\frac{\text{DIO}_t}{365},
```

```{math}
\text{Payables}_t
=\text{COGS}_t\times\frac{\text{DPO}_t}{365}.
```

Seasonal companies need quarterly or monthly schedules; annual days can hide a
peak funding requirement.

### Fixed assets

```{math}
\text{Net PP\&E}_t
=\text{Net PP\&E}_{t-1}
+\text{Capital expenditures}_t
-\text{Depreciation}_t
-\text{Disposals}_t
+\text{Acquisition and FX effects}_t.
```

Capacity, maintenance, expansion, construction timing, and useful lives should
support the capital expenditure and depreciation assumptions.

### Debt, interest, tax, and equity

Debt schedules require opening principal, mandatory amortization, optional
repayment, new borrowing, maturity, rate, currency, security, and covenant
terms. Interest generally uses average debt and a rate consistent with the
forecast currency and period.

Retained earnings roll forward with net income and distributions. Share
issuance, repurchases, other comprehensive income, and NCI require separate
schedules. Tax forecasts should distinguish current cash tax from deferred tax
and discrete items.

## Worked example: one-year integrated forecast

The opening balance sheet is the ending balance sheet from Lesson 4.1:

| Opening balance | USD m |
| --- | ---: |
| Cash | 60.00 |
| Receivables | 140.00 |
| Inventory | 150.00 |
| Net PP&E | 440.00 |
| **Total assets** | **790.00** |
| Payables | 105.00 |
| Debt | 230.00 |
| Equity | 455.00 |

### Assumptions

| Driver | Forecast |
| --- | ---: |
| Revenue growth | 8.0% |
| Gross margin | 40.0% |
| EBIT margin | 16.0% |
| DSO | 51.1 days |
| DIO | 91.25 days |
| DPO | 63.875 days |
| Depreciation | USD 50.00m |
| Capital expenditures | USD 70.00m |
| Interest expense | USD 25.00m |
| Tax rate | 25.0% |
| Debt repayment | USD 20.00m |
| Dividends | USD 30.00m |

The days assumptions preserve the prior year-end relationships for teaching
purposes. A real model would use seasonal averages and operating evidence.

### Income statement

```{math}
\text{Revenue}=1{,}000(1+0.08)=1{,}080.00,
```

```{math}
\text{COGS}=1{,}080(1-0.40)=648.00,
```

```{math}
\text{EBIT}=1{,}080(0.16)=172.80.
```

| Forecast income statement | USD m |
| --- | ---: |
| Revenue | 1,080.00 |
| COGS | (648.00) |
| Operating expenses excluding depreciation | (209.20) |
| Depreciation | (50.00) |
| EBIT | 172.80 |
| Interest | (25.00) |
| Tax at 25% | (36.95) |
| **Net income** | **110.85** |

### Operating schedules

```{math}
\text{Receivables}=1{,}080\times\frac{51.1}{365}=151.20,
```

```{math}
\text{Inventory}=648\times\frac{91.25}{365}=162.00,
```

```{math}
\text{Payables}=648\times\frac{63.875}{365}=113.40.
```

Net operating working capital rises from
\(140+150-105=185.00\) to \(151.20+162.00-113.40=199.80\), a USD 14.80m use of
cash.

Net PP&E is:

```{math}
440+70-50=460.00.
```

### Cash flow and FCFF

```{math}
\text{CFO}
=110.85+50.00-14.80
=146.05.
```

After capital expenditure, debt repayment, and dividends:

```{math}
\Delta\text{Cash}
=146.05-70.00-20.00-30.00
=26.05.
```

Ending cash is USD 86.05m.

FCFF uses operating profit before financing:

```{math}
\begin{aligned}
\text{FCFF}
&=\text{EBIT}(1-T)+\text{D\&A}
-\text{Capital expenditures}
-\Delta\text{Operating working capital}\\
&=172.80(1-0.25)+50.00-70.00-14.80\\
&=94.80.
\end{aligned}
```

### Closing balance sheet

Debt falls to USD 210.00m. Equity becomes:

```{math}
455.00+110.85-30.00=535.85.
```

| Closing balance | USD m |
| --- | ---: |
| Cash | 86.05 |
| Receivables | 151.20 |
| Inventory | 162.00 |
| Net PP&E | 460.00 |
| **Total assets** | **859.25** |
| Payables | 113.40 |
| Debt | 210.00 |
| Equity | 535.85 |
| **Total liabilities and equity** | **859.25** |

The model balances without an unexplained account. Closing cash was derived
from the cash flow statement and independently agrees with the balance sheet.

## Sensitivity and stress cases

Cases should change coherent driver sets, not isolated outputs:

| Driver | Downside | Base | Upside |
| --- | ---: | ---: | ---: |
| Revenue growth | (3.0%) | 8.0% | 12.0% |
| EBIT margin | 13.0% | 16.0% | 17.0% |
| DSO | 65 days | 51.1 days | 48 days |
| DIO | 105 days | 91.25 days | 85 days |
| Capital expenditures | USD 80m | USD 70m | USD 75m |
| Refinancing rate | 9.0% | 7.0% | 6.0% |

The downside links weaker demand to margin pressure, slower collections,
inventory accumulation, continued investment, and more expensive refinancing.
The model should report at least:

- minimum cash and any funding need;
- net debt, leverage, interest coverage, and covenant headroom;
- FCFF and the bridge from base;
- ROIC and working-capital days;
- which assumption causes the first liquidity or solvency threshold breach.

A sensitivity changes one or two variables to measure local response. A stress
case tells a coherent adverse story and must include management actions such as
cutting discretionary capital expenditure, reducing dividends, drawing a
facility, or changing inventory purchases—with implementation limits stated.

## Model review and traceability

### Required mechanical checks

- assets equal liabilities plus equity in every period and scenario;
- cash movement equals CFO plus CFI plus CFF;
- retained earnings, debt, fixed assets, leases, taxes, and share count roll
  forward;
- historical totals match the controlling filing;
- percentages, decimals, currency, units, dates, and signs are consistent;
- no formula skips a forecast period or points into another scenario;
- no hardcoded value appears inside a forecast formula without a documented
  reason.

### Required economic checks

- growth is consistent with volume, price, capacity, market size, and FX;
- margins reconcile to cost drivers and operating leverage;
- working-capital days are plausible for the business and season;
- depreciation follows the asset base and capital program;
- debt repayment does not exceed available cash or contractual flexibility;
- taxes and discount-rate inputs use consistent currencies and nominal or real
  conventions;
- terminal assumptions do not contradict competitive economics.

Traceability means a reviewer can move from an output to a formula, assumption,
adjustment, reported value, and source document. Reproducibility requires
preserving the source vintage and scenario configuration
{cite}`wilkinson2016fair`.

## Synthesis: model review memo

Use a compact review memo:

1. **Purpose and scope:** decision, issuer, forecast horizon, currency, units,
   and source vintage.
2. **Historical conclusion:** revenue quality, normalized earnings, capital
   efficiency, cash conversion, leverage, and reporting-quality issues.
3. **Forecast:** three to five drivers, FCFF, funding, and closing leverage.
4. **Cases:** base, downside, upside, threshold breaches, and management
   actions.
5. **Model controls:** checks passed, checks unresolved, circularity policy, and
   reviewer.
6. **Limitations:** missing disclosures, accounting uncertainty, estimation
   risk, and facts that would change the conclusion.

The memo should not repeat every model line. It should identify the small set of
assumptions and evidence that control the conclusion.

## Checks and limitations

- A balanced model can still be economically wrong.
- A cash plug can hide a missing schedule; derive cash from cash flow and use
  the balance sheet as a check.
- Interest based on ending debt can create a circularity with cash sweeps.
- Annual models can miss intra-year liquidity needs.
- Scenario labels are not probabilities unless a probability model is
  explicitly supported.
- Forecast precision should not exceed the quality of source disclosures and
  operating evidence.

## Practice

Using the base example, replace DSO with 60 days while keeping every other base
assumption unchanged.

1. Calculate forecast receivables.
2. Calculate the incremental cash use relative to the base case.
3. Recalculate CFO, ending cash, and FCFF.
4. Explain why EBIT and net income do not change in this simplified case.
5. Write a three-sentence review conclusion.

```{dropdown} Suggested answer
Receivables become \(1{,}080(60/365)=177.53\) USD m, USD 26.33m above the base
forecast. Operating working capital uses an additional USD 26.33m, so CFO falls
from USD 146.05m to USD 119.72m. Ending cash falls from USD 86.05m to USD
59.72m, and FCFF falls from USD 94.80m to USD 68.47m. EBIT and net income do not
change because this simplified model holds revenue recognition and credit-loss
expense constant; a fuller downside might also reduce revenue or increase bad
debt. A sound memo would flag collection deterioration, quantify the cash and
FCFF effect, and identify customer aging and credit-loss evidence needed before
accepting the assumption.
```
