# Capstone Projects

These projects turn the course into an applied experience and can be built gradually as new notebooks.

## 1. Mexican macro dashboard

Build a dashboard with Banxico and FRED time series:

- inflation;
- policy rate;
- exchange rate;
- short-term rates;
- rolling correlations.

## 2. Bond analyzer

Value fixed-income instruments and study sensitivity:

- clean and dirty price;
- yield to maturity;
- duration;
- convexity;
- rate movement scenarios;
- interactive comparison of exact repricing and duration-convexity approximation.

## 3. Volatility simulator

Compare historical volatility against ARCH/GARCH models:

- returns;
- volatility clustering;
- model fitting;
- forecasting;
- visual evaluation.

## 4. Portfolio comparator

Build and compare strategies:

- mean-variance;
- minimum variance;
- maximum Sharpe ratio;
- risk parity as an extension;
- simple backtesting.

## 5. Option pricer

Create an interactive pricer:

- Black-Scholes;
- Greeks;
- payoff;
- binomial tree;
- Monte Carlo simulation;
- interactive Greeks dashboard.

## 6. Yield curve laboratory

Build an interest-rate analysis notebook:

- discount factor bootstrapping;
- spot and forward curves;
- Nelson-Siegel fitting;
- curve movement scenarios;
- short-rate simulation.
